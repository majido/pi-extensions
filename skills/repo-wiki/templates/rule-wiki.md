# Repo wiki

- Read `docs/wiki/index.md` at session start; open only pages relevant to the task.
- Before finishing: check whether **your diff** invalidates any wiki page. If yes, update
  the affected sections surgically in the same change and refresh the `Last verified` footer.
- No update needed for cosmetic, test-only, or purely internal refactoring changes.
- Never regenerate a whole page; edit stale sections only, matching existing style.
- Any new `docs/wiki/` page must be linked from `docs/wiki/index.md` in the same commit.
